# Global compute publications and complete source explorers

Baseline: `925936b`, following the portable research workspace release.

The app now includes the complete public Epoch AI GPU-cluster CSV and the complete
AI data-center ZIP: **2,085 additional source rows** across seven tables. The
facility directory contains **6,471 native records in six collections**; the
1,508 supporting timeline, deployment and equipment rows are separately
searchable in the full research index and their own explorer. All prior dossiers,
evidence revisions, community geometry and original attachments remain intact.

- **Global GPU clusters** offers a rotatable/zoomable source map, intersecting
  country/owner/accelerator/certainty/history filters, pagination, three-record
  comparison, predecessor/successor links, all 57 native fields, source citations,
  notes, shelf bookmarks and complete filtered JSON/CSV exports.
- **AI data center buildout** exposes all six source tables. Center dossiers link
  to dated development and chip deployments. Select independent timeline metrics,
  inspect every source point, compare three centers and download the exact original
  ZIP. Equipment references retain their own manufacturers, native measurements,
  citations and source-review notes.
- **Global coverage** compares country/source-label counts across all six native
  collections. Each nonempty cell opens the exact directory scope. Exports contain
  all filtered country rows or all complete source publications, excluding notes.
- Landscape collection navigation, the primary directory, full research search,
  saved views and source bookmarks connect these views. URL state retains filters,
  selected records, comparison sets, pagination and the GPU camera.

[Acquisition, licensing and measurement decisions](../research/2026-10-22-global-publications.md)
record the source boundaries. Global coverage is a source-coverage view, not a
worldwide facility census. Anonymous records stay anonymous. The original 79-site
capacity model is not overwritten by newer publisher estimates. Missing source
coordinates and physical campus geometry remain explicit.

## Validation

The global-publication workflow suite exercises both HTTP entrypoints and turns
networking off after loading the embedded standalone for its interactions and
exports. HTTP reloads temporarily restore networking to retrieve the HTML itself;
the standalone's subsequent interactions stay offline. It checks exact ZIP bytes,
complete exports, native records, source relations, comparison, navigation, saved
work and 1440/1024/390/320-pixel layouts. Native `file://` navigation remains a CI
check; the managed local browser cannot open it.

Fresh release receipts and the final broad-regression results are recorded in the
pull request. The master implementation issue remains open for further reviewed
physical imagery, utility/fiber correspondence and broader global source work.
